# 时间线 GUI 使用说明

由 `python tools/build_catalog.py` 扫描真实注册表生成，**请勿手改**。

键位来自 `gui/shortcuts.py`，坐标 / 缩放常量来自 `gui/timeline_coordinate.py`，
磁吸阈值来自 `gui/timeline_snap.py`，落轨策略来自 `gui/asset_placement.py`。
文档不重复定义任何数值。

## 坐标系

所有组件共用一份坐标换算（`TimelineCoordinate`）：

- `time_to_x(t)` / `x_to_time(x)`，含 scroll 与轨道头宽度
- 一次手势开始时对坐标系做快照，手势期间不受滚动 / 缩放变化影响
- `grab_offset = 按下时的鼠标时间 - 元素 start`，整个拖动过程保持不变，
  所以拖动只改 start，不改 duration
- 帧量化（`snap_time`）永远是**最后一步**，磁吸算完再量化

## 缩放

- 档位：25%、50%、75%、100%、150%、200%、400%、800%
- 100% = 80 px/s
- `Ctrl + 滚轮` 以鼠标所在时间为锚点缩放，锚点在屏幕上不动
- 下拉框选档位时以画布中心为锚点

## 磁吸

- 阈值是**像素**：10px，换算成时间再与 0.12s 取小
- 吸附目标：播放头、相邻片段的头 / 尾、时间 0、标记点
- 头尾同时可吸时按距离竞争，谁近吸谁
- `Ctrl+M` 开关磁吸

## 素材落轨策略

从素材库拖进时间线时，落到哪条轨道由策略表决定，GUI 里不再散落硬编码：

| 素材角色 | 元素类型 | 默认轨道 | 备选轨道 | 避免重叠 |
| --- | --- | --- | --- | --- |
| 视频（`video`） | `video` | `V1` | `V2`、`V3`、`V4` | 是 |
| 图片（`image`） | `overlay` | `V3` | `V4`、`V2`、`V1` | 是 |
| 叠加素材（`overlay`） | `overlay` | `V4` | `V3`、`V2` | 是 |
| 背景音乐（`music`） | `audio` | `A1` | `A2`、`A3` | 是 |
| 人声（`voice`） | `audio` | `A2` | `A3`、`A1` | 是 |
| 音效（`sfx`） | `audio` | `A3` | `A2`、`A1` | 是 |
| 字幕（`caption`） | `caption` | `T1` | `T2` | 否 |
| 文字（`text`） | `text` | `T2` | `T1` | 否 |
| 冻结帧（`freeze`） | `freeze` | `V1` | `V2`、`V3`、`V4` | 是 |

- 默认轨道被占 → 顺延到备选轨道，**不覆盖**已有元素
- 明确指定轨道（拖到某条轨道上）时以指定为准；类型不匹配或轨道锁定则拒绝并提示
- 字幕 / 文字不做顺延：同轨叠字是正常需求

## 标记

标记以兼容扩展的方式存在 `meta.markers`：Remotion 不读它，为空时整个字段不写，
v1 / v2 schema 都显式允许。类型：

| type | 名称 |
| --- | --- |
| `normal` | 普通 |
| `highlight` | 高潮 |
| `transition` | 转场 |
| `caption` | 字幕 |
| `sfx` | 音效 |
| `ai_highlight` | AI 精彩点 |
| `voice_peak` | 配音重音 |
| `voice_pause` | 配音停顿 |

## 快捷键

### 播放与播放头

| 键位 | 作用 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `Left` | 上一帧 |
| `Right` | 下一帧 |
| `Shift+Left` | 后退 1 秒 |
| `Shift+Right` | 前进 1 秒 |
| `Home` | 播放头回到开头 |
| `End` | 播放头跳到结尾 |

### 剪辑

| 键位 | 作用 |
| --- | --- |
| `Ctrl+B` | 在播放头处分割选中片段 |
| `Shift+F` | 在播放头处加冻结帧（定格） |
| `Delete / Backspace` | 删除选中元素（支持多选） |
| `Ctrl+C` | 复制选中元素 |
| `Ctrl+X` | 剪切选中元素 |
| `Ctrl+V` | 粘贴到播放头位置 |
| `Ctrl+D` | 原地复制一份 |
| `Alt+Left` | 选中元素左移一帧 |
| `Alt+Right` | 选中元素右移一帧 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y / Ctrl+Shift+Z` | 重做 |

### 选择

| 键位 | 作用 |
| --- | --- |
| `Ctrl+A` | 选中当前所有元素 |
| `Up` | 选上一条轨道上同时刻的元素 |
| `Down` | 选下一条轨道上同时刻的元素 |

### 标记

| 键位 | 作用 |
| --- | --- |
| `M` | 在播放头处打标记 |
| `Shift+M` | 删除播放头附近的标记 |
| `Ctrl+Left` | 跳到上一个标记 |

### 鼠标操作

| 操作 | 作用 |
| --- | --- |
| 拖动片段本体 | 移动，可跨同类型轨道 |
| 拖动片段左右边缘 | 裁剪入点 / 出点 |
| Alt + 拖动片段 | 拖出一个副本 |
| 空白处拖动 | 框选多个元素 |
| Ctrl + 点击片段 | 加选 / 取消选中 |
| 刻度区拖动 | 拖动播放头 |
| Ctrl + 滚轮 | 以鼠标位置为锚点缩放时间线 |
| Shift + 滚轮 | 横向滚动 |
| 双击片段 | 在属性面板里聚焦该元素 |
| 从资源管理器拖文件进来 | 自动导入素材库并落到落点 |

## 拖动过程中不会发生的事

拖动 / 裁剪只碰 GUI 与 `TimelineModel`：不解码视频、不调 FFmpeg、不起 Remotion、
不请求任何 AI 接口。一次手势结束才提交一条模型记录（也就是一步 Undo）。
